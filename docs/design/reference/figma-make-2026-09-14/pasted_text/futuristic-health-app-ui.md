Design a premium futuristic mobile app UI showcase inspired by high-end HealthTech and Fitness applications.

STYLE:
Premium futuristic HealthTech UI, soft neumorphism, modern mobile dashboard, sophisticated 3D visualization, AI-powered fitness technology, minimal Scandinavian product design, soft industrial design, premium SaaS product presentation.

The design must feel like a real commercially designed mobile application, not a generic AI-generated UI.

COMPOSITION:
Create a clean 1:1 square presentation canvas.

Show 3 large smartphone application screens side by side with subtle differences in scale and position.

The three screens should form a polished product showcase:
- Left screen: main dashboard
- Center screen: analytics / activity dashboard
- Right screen: immersive real-time activity interface

Keep generous spacing between the screens.
Do not overlap them heavily.
Do not create extreme rotations.
Use very subtle perspective and slight rotation only.
The presentation should feel clean, premium and intentional.

BACKGROUND:
Use a muted blue-gray background.

Color:
#AEBCCC / #B2BFCE

Flat matte background with extremely subtle tonal variation.
Very soft ambient shadows underneath each screen.
No texture.
No environment.
No objects outside the UI.

MOBILE SCREEN:

Approximately 9:19 aspect ratio.
Very large rounded corners.
Corner radius approximately 32–42px.
Soft off-white / pale blue-gray surface.
No realistic phone bezel.
No metallic phone frame.

Use very subtle soft shadows:
large diffuse ambient shadow,
low opacity,
no hard edges.
